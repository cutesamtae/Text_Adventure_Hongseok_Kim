Escape the Damaged Spaceship
Author: Hongseok Kim

GOAL
The spaceship is broken and player needs to escape.
Find the keycard and go to the escape shuttle.

HOW TO WIN
Start a new game and type these commands in order.

1. go west
2. get keycard
3. inspect keycard
4. go east
5. go north
6. go north
7. escape

After escape command, the shuttle leaves the ship
and player wins the game.

SELF-GUIDED OBJECTIVE
I added inspect command.
After getting the keycard, type inspect keycard.
It shows information about the keycard and tells
which door can open with it.

OTHER ROOMS
Engine Room:
From Main Hub, type go east.
Type go west to come back.

Observation Deck:
From Storage Bay, type go north.
Type go south to come back.

These rooms are for exploring.
Player does not need to visit them to win.

COMMANDS
help - Shows the command list.
look - Shows current room, items, inventory, and exits.
go [direction] - Moves to another room.
get keycard - Picks up the keycard if it is in the room.
inspect keycard - Shows keycard information after getting it.
escape - Wins the game when player is in Escape Shuttle.
quit - Ends the game.
